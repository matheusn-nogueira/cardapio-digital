# Cardápio digital da Casa dos Fundos

Cardápio online de pedidos da Casa dos Fundos, publicado em https://cardapio.casadosfundos.cloud. Lê o catálogo e grava os pedidos no Supabase do ERP.

```bash
npm install
npm run dev
```

Comandos, deploy, categorias, marcas, notificações push e regras do domínio estão no [CLAUDE.md](CLAUDE.md).
